# 日本酒イベント・結果発表カレンダー（記事準備用）

最終更新: 2026-10-29

**目的**: 「結果が出た直後の速報・一覧記事」は、検索のクリック率が高い（例: 全国新酒鑑評会の金賞受賞酒の速報は、クリック率11.4%・掲載順位4.7位。「全国新酒鑑評会 2026 結果」「日本酒 金賞 一覧 2026」は、クリック率10〜13%）。結果発表の日に、すぐ出せるよう、前もって準備する。

**使い方**
- `sake-article-routine` の手順2（リサーチ）で、まずこの表を見る。今日から30日以内に、結果発表・開催がある行は、題材の候補にする。
- 日付は「確定」と「予想」を分けて書く。**予想の行は、公式サイトで日程を確認してから動く**（毎年変わる）。
- 速報記事は、一覧表（受賞酒・銘柄・蔵・都道府県）を中心にし、結果が出る前に、記事の枠（背景、評価の仕組み、過去の結果）まで作っておく。
- 新しい結果が出たら、前年の記事を作り直さず、**同じ記事IDを更新**する（検索の評価を引き継ぐため）か、新しい年の記事を作って旧記事から内部リンクする。

## 更新のルール
- 結果発表や日程の確認ができたら、「予想」の行を「確定」の表に移す。
- 新しいイベント・結果が出たら、この表に行を足す。
- この表の日程は、あくまで記事準備の目安。記事には、公式の発表をもとに、一次情報を書く。
